# Nível 0 — Pré-requisitos

Antes do Vue, você precisa estar confortável com a plataforma web e o ambiente Node.

## Objetivos

- Manipular o DOM com JavaScript puro.
- Consumir APIs REST com `fetch` + `async/await`.
- Usar Git para versionar e Node/npm para instalar dependências.
- Entender o ciclo: HTML estrutura, CSS apresenta, JS comporta.

## Tópicos

### HTML5
- Tags semânticas (`<header>`, `<main>`, `<section>`, `<article>`).
- Formulários (`input`, `select`, `textarea`, `label`, atributos `required`, `pattern`).
- Acessibilidade básica (`alt`, `aria-label`, ordem de tabulação).

### CSS
- Seletores (classe, id, descendente, pseudo-classes `:hover`, `:focus`).
- Box model (margin, padding, border, box-sizing).
- Flexbox e Grid.
- Media queries / responsividade.
- Variáveis CSS (`--cor-primaria`).

### JavaScript moderno (ES6+)
- `let`, `const`, escopo de bloco.
- Arrow functions, this léxico.
- Destructuring, spread/rest, template literals.
- Módulos `import` / `export`.
- `Promise`, `async/await`, `try/catch`.
- `fetch` API.
- Métodos de array: `map`, `filter`, `reduce`, `find`, `some`, `every`.
- Métodos de objeto: `Object.keys`, `Object.entries`, `Object.assign`.

### Git
- `init`, `clone`, `add`, `commit`, `push`, `pull`.
- Branches: `branch`, `checkout`, `merge`.
- `.gitignore`.
- Resolução de conflitos básica.

### Node.js + npm
- Instalar Node LTS.
- `npm init`, `npm install`, scripts em `package.json`.
- Diferença entre `dependencies` e `devDependencies`.
- `npx` para executar binários sem instalar globalmente.
