# Fundamentos de Lógica em JavaScript

Categoria dedicada aos **alicerces de raciocínio** que você usa em qualquer linguagem — e que aparecem o tempo todo no Vue (em `computed`, `v-if`, componentes recursivos, etc).

> Não é sobre Vue ainda. É sobre pensar como programador. Domine isto e o Vue fica fácil.

## Tópicos

| # | Tema | O que você vai dominar | Pasta |

| 02 | **Controle de fluxo** | Diferença real entre `return`, `break` e `continue` | [02-controle-de-fluxo/](02-controle-de-fluxo/) |

## Como estudar cada tema

Cada pasta tem **3 arquivos**, na ordem:

1. **`README.md`** — a explicação (teoria com exemplos comentados).
2. **`perguntas-respostas.md`** — o questionário. Tente responder **antes** de abrir a resposta.
3. **`desafios.md`** — exercícios práticos, do mais fácil ao mais difícil.

## Regras de ouro

- **Rode tudo**: cole os exemplos no console do navegador (F12) ou no [Node](https://nodejs.org). Ver acontecendo > ler.
- **Erre de propósito**: tire o caso base de uma recursão e veja o `Maximum call stack size exceeded`. Entender o erro é metade do aprendizado.
- **Explique em voz alta**: se você não consegue explicar para uma pessoa, você ainda não entendeu.
- **Conecte ao Vue**: ao final de cada explicação há uma seção *"Onde isso aparece no Vue"* — é o seu gancho com o mundo real.
